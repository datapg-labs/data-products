# Projects

Learner dbt projects, one directory each. Every project has a `README.md` that starts
like this — the `Authors:` line is what decides who can change the project:

```markdown
# BTC daily candles

Authors: @your-github-user

What it builds, from which tables, at what grain — and what you learned building it.
```

Start one from a reference project in `../reference/` or from scratch, under a name that
says what it builds. To work on an existing project, open a pull request that only adds
your handle to its `Authors:` line. See [CONTRIBUTING.md](../CONTRIBUTING.md).
